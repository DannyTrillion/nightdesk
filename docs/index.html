The asymmetry

Borrowing and liquidation do not get the same bar. This is the part a binary fresh/stale check cannot express at all.

Borrow needs
20%

Below this the price is too uncertain to size a new position against.

Liquidation needs
50%

Deliberately stricter. A borrower whose collateral is merely hard to value should not lose it because the oracle went quiet.

Agent outage
0%

No fresh attestation means confidence is zero. The system fails closed rather than trusting a dead agent.
